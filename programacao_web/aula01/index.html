Estilos: aparência da página

O HTML organiza e dá significado ao conteúdo. O navegador aplica uma aparência padrão aos elementos: por exemplo, os títulos costumam aparecer maiores, os links coloridos e os itens de listas recuados. Essas aparências padrão não são estilos definidos por esta página.

O que o HTML pode indicar

  • h1 a h6: níveis de título. O navegador costuma mostrar cada nível com tamanho diferente.
  • strong: conteúdo importante; costuma aparecer em negrito.
  • em: conteúdo enfatizado; costuma aparecer em itálico.
  • ul, ol e li: organizam itens em listas.
  • header, main, section e footer: organizam áreas da página pelo seu significado.

O que são estilos visuais

Cor de fundo, cor do texto, tipo e tamanho da fonte, margens, espaçamento, bordas e posição dos elementos são exemplos de estilos. O HTML sozinho não é a ferramenta adequada para controlar esses detalhes. Mais adiante, o CSS será usado para definir essa aparência.
